# Moving MyOS to a New Laptop

Checklist for setting up the MyOS development environment on a new machine.

## Required (without these, the project won't build)

### 1. System packages (apt)

Install on the new laptop:

    sudo apt update
    sudo apt install -y build-essential nasm qemu-system-x86 xorriso mtools gdb \
        libgmp3-dev libmpc-dev libmpfr-dev texinfo bison flex libisl-dev

Package list:

- `build-essential` — gcc, make, and basic build tools
- `nasm` — assembler for `boot.asm` and `isr.asm`
- `qemu-system-x86` — emulator to run `myos.iso`
- `xorriso`, `mtools` — used by `grub-mkrescue`
- `gdb` — debugger
- `libgmp3-dev`, `libmpc-dev`, `libmpfr-dev`, `libisl-dev`, `texinfo`, `bison`, `flex` — dependencies for building the cross-compiler

### 2. Cross-compiler `x86_64-elf-gcc`

Pick one:

- **Option A (fastest)**: copy `~/opt/cross/` from the old laptop via USB / external HDD / cloud storage. Size: ~500 MB–1 GB.
- **Option B**: rebuild from source (Binutils + GCC, 30–60 minutes).

Verify:

    ls ~/opt/cross/bin/x86_64-elf-gcc

It must exist.

### 3. Clone the GitHub repository

    git clone https://github.com/ALAZZA15/New_Kernel_LFS.git myos
    cd myos

### 4. Configure git identity

    git config --global user.name "ALAZZA15"
    git config --global user.email "elazza1926@gmail.com"

### 5. GitHub Personal Access Token (PAT)

- Create one at https://github.com/settings/tokens (classic, scope `repo`).
- Store it in a password manager (Bitwarden / KeePass / encrypted notes).
- Used as the "password" on the first `git push` from the new laptop.

## Optional (for convenience)

### 6. Editor / IDE

- VS Code + C/C++, Assembly, Makefile extensions
- Or `nano`, `vim`, `gedit`

### 7. Add the cross-compiler to PATH in `~/.bashrc`

    export PATH="$HOME/opt/cross/bin:$PATH"

Not required — the `Makefile` already uses absolute paths.

### 8. Ensure the old repository is clean before moving

On the old laptop:

    cd ~/osdev/myos
    git status

If there are uncommitted changes:

    git add .
    git commit -m "update"
    git push

## Do not copy

- `~/osdev/src/` — Binutils + GCC sources and build folders (can be deleted after `~/opt/cross/` is built)
- `linux-7.3.tar.xz` — not part of this project
- `myos.bin`, `myos.iso`, `*.o`, `iso/` — build artifacts, regenerated by `make iso`
- `~/opt/cross/` — except when using Option A above

## Setup order on the new laptop

    # 1. Install system packages
    sudo apt install -y build-essential nasm qemu-system-x86 xorriso mtools gdb \
        libgmp3-dev libmpc-dev libmpfr-dev texinfo bison flex libisl-dev

    # 2. Clone the repository
    git clone https://github.com/ALAZZA15/New_Kernel_LFS.git myos
    cd myos

    # 3. Configure git
    git config --global user.name "ALAZZA15"
    git config --global user.email "elazza1926@gmail.com"

    # 4. Copy ~/opt/cross/ from the old laptop (or rebuild from source)

    # 5. Build and run
    make iso
    make run

## Important notes

- If `~/opt/cross/` is at a different path on the new laptop (not `/home/<user>/opt/cross`), update the `CROSS := $(HOME)/opt/cross/bin` line in `Makefile`.
- A GitHub PAT cannot be viewed again after its creation page is closed. If lost, generate a new one.
- After the first successful `git push` from the new laptop, git will cache the token (depending on the configured credential helper).
